  1. 검색
    지식 문서 검색K1 반품 정책 › 단순변심 반품 배송비를 찾았습니다.
  2. 검사
    근거 일치 검사 근거와 맞음답의 금액과 조건이 K1에 있는 그대로인지 확인했습니다.
  3. 모델
    두 번째 문의: 정책 밖 예외"하루 지났지만 받아 달라"는 예외 요청은 AI가 승인할 수 없는 일입니다.
  4. 인계
    상담원에게 넘김 정책 밖 예외 요청대화·근거 K1·넘기는 이유가 요약과 함께 전달됩니다.

  1. 고객 화면에서 예시 고객을 고르고 반품·배송·취소를 물어봅니다.
  2. 상담원 연결이 뜨면 상담원 화면에서 요약·근거를 보고 답합니다.
  3. 운영 화면에서 해결률, 걸러진 답변, 응답 시간을 확인합니다.

문의 한 건이 처리되는 순서

고객에게 나가는 글은 근거 검사를 지납니다. 검사에 걸린 초안은 보류되고, 다시 써도 맞지 않으면 상담원에게 넘어갑니다.

  1. 문의고객이 웹·채팅·API로 질문합니다.
  2. 맥락 확인·지식 검색앞선 대화를 보고 관련 문서를 찾습니다.
  3. 도구 호출허용된 주문 조회·취소·반품 확인만 부릅니다.
  4. 근거 있는 답변·출처근거 ID와 함께 답하고 출처를 보여 줍니다.
  5. 보류·인계근거가 부족하거나 사람의 판단이 필요하면 멈춥니다.
  6. 상담원 확인요약·대화·근거·사유를 보고 이어서 답합니다.
  7. 운영 지표해결 여부, 오류, 응답 시간을 집계합니다.
